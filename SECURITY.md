# Security Policy / Sicherheitsrichtlinie

## Deutsch

### Geltungsbereich

Diese Richtlinie gilt für Dungeon Settlers Delvers: Core und seine MelonLoader- und BepInEx-Pakete.

Das Projekt befindet sich in der Vorabphase. Sicherheitskorrekturen sind für die jeweils aktuelle veröffentlichte Version vorgesehen. Für ältere Versionen werden keine separaten Sicherheitsupdates zugesichert.

### Eine Sicherheitslücke melden

Bitte melde vermutete Sicherheitslücken vertraulich über [GitHub: Report a vulnerability](https://github.com/Fre-yin/DNST-Delvers-Core/security/advisories/new).

Erstelle dafür kein öffentliches Issue. Bitte veröffentliche technische Details erst nach Abstimmung, damit eine Prüfung und gegebenenfalls eine Korrektur möglich sind.

Hilfreiche Angaben:

- Core-Version und betroffener Loader mit Versionsnummer
- Spielversion oder Steam-Build und Windows-Version, soweit relevant
- Beschreibung der möglichen Auswirkungen
- Schritte zur Reproduktion oder ein möglichst kleines Beispiel
- Bereinigte Protokolle oder Screenshots, falls hilfreich

Sende keine Passwörter, Zugangstokens, privaten Schlüssel oder persönlichen Spielstände. Entferne persönliche Daten aus Anhängen.

Das Projekt wird in der Freizeit betreut. Es gibt keine garantierte Antwort- oder Behebungsfrist. Rückfragen, Bewertung und nächste Schritte werden über die private GitHub-Meldung besprochen.

Allgemeine Fehler und Funktionswünsche ohne Sicherheitsbezug können über die öffentlichen [Issues](https://github.com/Fre-yin/DNST-Delvers-Core/issues) gemeldet werden.

## English

### Scope

This policy applies to Dungeon Settlers Delvers: Core and its MelonLoader and BepInEx packages.

The project is in prerelease development. Security fixes are intended for the latest published version. Separate security updates for older versions are not guaranteed.

### Reporting a vulnerability

Please report suspected security vulnerabilities privately through [GitHub: Report a vulnerability](https://github.com/Fre-yin/DNST-Delvers-Core/security/advisories/new).

Do not open a public issue for a security vulnerability. Please coordinate disclosure of technical details so that the report can be investigated and, where necessary, a fix prepared.

Useful information includes:

- Core version and affected loader with its version
- Game version or Steam build and Windows version, where relevant
- Description of the potential impact
- Reproduction steps or a minimal example
- Sanitized logs or screenshots, if helpful

Do not send passwords, access tokens, private keys, or personal game saves. Remove personal information from attachments.

This project is maintained in spare time. Response and resolution times are not guaranteed. Questions, assessment, and next steps will be discussed through the private GitHub report.

General bugs and feature requests without security implications can be reported through public [Issues](https://github.com/Fre-yin/DNST-Delvers-Core/issues).
